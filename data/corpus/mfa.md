# Authentification multifacteur (MFA)

La MFA est obligatoire pour la messagerie, le VPN et le portail https://moncompte.acme.fr.

## Première configuration

1. Installer l'application d'authentification indiquée par la DSI sur le téléphone.
2. Se connecter à https://moncompte.acme.fr, rubrique « Sécurité ».
3. Scanner le QR code affiché avec l'application.
4. Saisir le code à 6 chiffres pour confirmer.

## Changement de téléphone

Avant de rendre l'ancien téléphone, ajouter le nouveau dans https://moncompte.acme.fr, rubrique « Sécurité ». Si l'ancien téléphone est perdu, appeler le support au poste 4242 : une vérification d'identité est faite par votre responsable.

## Notification inattendue

Si vous recevez une demande de validation MFA que vous n'avez pas déclenchée, **refusez-la** et changez votre mot de passe sur https://moncompte.acme.fr. Signalez ensuite l'incident au support.
