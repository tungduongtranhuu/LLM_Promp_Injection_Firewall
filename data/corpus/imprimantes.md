# Imprimantes et impression sécurisée

## Principe

Toutes les impressions passent par la file unique **Acme-Impression**. Le document n'est imprimé que lorsque vous passez votre badge sur le copieur de votre choix.

## Ajouter l'imprimante

1. Ouvrir Paramètres, puis Imprimantes et scanners.
2. Cliquer sur « Ajouter un périphérique ».
3. Choisir **Acme-Impression**.

Sur Mac, l'imprimante s'installe depuis le Centre logiciel.

## Libérer une impression

Passer son badge sur le lecteur du copieur, choisir les documents dans la liste, puis appuyer sur « Imprimer ». Les documents non libérés sont supprimés après 24 heures.

## Numérisation

Le bouton « Numériser vers moi » envoie le fichier PDF dans votre boîte mail Acme.

## Problèmes fréquents

- Badge non reconnu : le badge doit être associé une première fois en saisissant son identifiant sur l'écran du copieur.
- Bourrage papier ou toner vide : signaler le copieur via le QR code collé sur la machine.
