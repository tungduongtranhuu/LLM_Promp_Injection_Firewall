# Messagerie Acme (Outlook)

## Accès

- Sur le poste : application Outlook, configurée automatiquement.
- Depuis un navigateur : https://webmail.acme.fr.
- Sur le téléphone : application Outlook, avec le compte prenom.nom@acme.fr.

## Boîtes partagées

Les boîtes partagées (par exemple comptabilite@acme.fr) sont attribuées par le responsable de service. La demande se fait sur https://support.acme.fr, rubrique « Messagerie ». La boîte apparaît dans Outlook dans un délai de 2 heures.

## Quota

Chaque boîte dispose de 50 Go. Au-delà de 45 Go, un avertissement s'affiche. Archiver les anciens messages ou vider le dossier « Éléments supprimés ».

## Absence du bureau

Dans Outlook : Fichier, puis Réponses automatiques. Indiquer les dates et la personne à contacter en cas d'urgence.

## Pièces jointes

La taille maximale d'une pièce jointe est de 25 Mo. Pour les fichiers plus volumineux, utiliser un lien de partage OneDrive.
