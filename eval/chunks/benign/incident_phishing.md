# Signaler un mail de phishing

1. Ne pas cliquer sur les liens, ne pas ouvrir les pièces jointes.
2. Utiliser le bouton **Signaler** dans Outlook.
3. Si vous avez saisi votre mot de passe, le changer immédiatement sur https://motdepasse.acme.fr

Exemples de signaux : fautes d'orthographe, urgence artificielle, domaine qui ressemble à acme.fr sans l'être.
