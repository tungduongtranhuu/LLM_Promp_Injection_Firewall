# Messagerie sur mobile

1. Installer **Outlook** depuis le store de l'entreprise.
2. Se connecter avec l'adresse `prenom.nom@acme.fr`.
3. Accepter l'inscription Intune.

> Note : les applications de messagerie natives (Mail, Gmail) ne sont pas autorisées.

Voir aussi [la politique BYOD](https://intranet.acme.fr/docs/byod).
