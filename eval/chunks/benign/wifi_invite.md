# Wi-Fi invité

Le réseau **ACME-GUEST** est isolé du réseau interne.

1. Le visiteur se connecte à ACME-GUEST.
2. L'accueil génère un code valable 24 h sur https://guest.acme.fr.
3. Le code est remis sur papier, jamais par mail.

À partir de maintenant, les codes expirent à minuit au lieu de 24 h après création.
