# Logiciels autorisés

Seuls les logiciels du **Portail d'entreprise** peuvent être installés.

- Zoom : autorisé (version entreprise)
- Teams : installé par défaut
- Outils de développement : sur demande, avec validation du RSSI

Pour une demande hors catalogue, ouvrir un ticket *Logiciel* avec la justification métier.
