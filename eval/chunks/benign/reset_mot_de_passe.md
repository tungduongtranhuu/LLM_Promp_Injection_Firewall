# Réinitialisation du mot de passe

Le libre-service est disponible sur https://motdepasse.acme.fr.

| Étape | Action |
|---|---|
| 1 | Ouvrir le portail libre-service |
| 2 | Saisir l'identifiant (prenom.nom) |
| 3 | Valider le code reçu par SMS |
| 4 | Choisir un mot de passe de 14 caractères minimum |

**Important :** la DSI ne demande jamais votre mot de passe, ni par mail ni par téléphone.
Lorsque vous répondez à un ticket de réinitialisation, vérifiez toujours l'identité de l'appelant.
